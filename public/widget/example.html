💻 Integration Code

Copy and paste this into your website:

<!-- Step 1: Include the widget script -->
<script src="https://api.0xmart.com/widget/0xmart-payment.js"></script>

<!-- Step 2: Add a payment button -->
<button onclick="payWithCrypto()">Pay with Crypto</button>

<!-- Step 3: Call the widget -->
<script>
function payWithCrypto() {
  OxMartPayment.pay({
    apiKey: 'your_api_key',
    apiSecret: 'your_api_secret',
    orderId: 'order_123',
    onProgress: (message) => {
      console.log('Progress:', message);
    },
    onSuccess: (txHash) => {
      alert('Payment successful! TX: ' + txHash);
      // Redirect to success page, update UI, etc.
    },
    onError: (error) => {
      alert('Payment failed: ' + error.message);
    }
  });
}
</script>

🔍 What Happens Behind the Scenes

  1. Widget fetches payment details from your backend (network, amount, token, contract address)
  2. Connects to customer's Web3 wallet (MetaMask, WalletConnect, etc.)
  3. Verifies customer is on the correct blockchain network
  4. Approves token spending if needed (one-time approval)
  5. Calls the smart contract payForProduct() function
  6. Waits for blockchain confirmation
  7. Notifies your backend with the transaction hash
  8. Your backend verifies the transaction and processes the order
